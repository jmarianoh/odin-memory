# Cambios 0.15.0

Fase F4.1: CLI base. `bin/odin.js` pasa de un esqueleto de dos comandos a un lanzador de la CLI completa de lectura, escritura y mantenimiento.

## Archivos a crear

- `src/cli/index.js` (`createCli`, `run`, despacho), `src/cli/runtime.js`, `src/cli/config.js`, `src/cli/project.js`, `src/cli/init-config.js`, `src/cli/usage.js` (se copia de `fuentes/src/cli/usage.js`).
- `src/cli/commands/{search,save,delete,timeline,context,stats,backup,init,mcp,projects}.js`.
- Tests: `test/unit/cli/{helpers,dispatch,read,write,backup,init,projects,details}.test.js`.
- Documentación: `implementacion/15-cli/{README,01-comandos-memoria,02-respaldo-e-init,03-proyectos,04-mcp-y-uso}.md`.

## Archivos a modificar

- `bin/odin.js`: ahora solo comprueba la versión de Node y delega en `run(process.argv.slice(2))` (se copia de `fuentes/bin/odin.js`).
- `test/unit/version.test.js`: `odin version` imprime `odin <versión>` (antes `odin-memory <versión>`).
- `package.json`: versión `0.15.0`.
- `implementacion/manifest.json`, `50-plan-construccion.md`.

## Migraciones de esquema

Ninguna.

## Notas

- Comandos nuevos: `mcp`, `init`, `search`, `save`, `delete` (observación, `session`, `prompt`, `project`), `timeline`, `context`, `stats`, `export`, `import`, `projects` (`list`, `merge`, `consolidate`, `prune`, `alias`). `version` y `help` ya existían; su salida cambia (`odin <versión>` y el texto de uso completo).
- `projects rescue-ownership` y el uso correspondiente llegan con el diario de sincronización (F5).
- Mientras `mem_doctor` no esté registrado (F6), `odin mcp` expone 22 herramientas aunque los perfiles declaren 23 (`agent`) y 27 (`all`).
- El texto de `help` lista solo los comandos que existen.
